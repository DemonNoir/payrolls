# ☁️ Cloud Sync (GitHub Gist) & Secret Button Walkthrough

## 📌 บทนำ (Overview)
เพิ่มระบบ **Cloud Sync & Backup** โดยใช้ **GitHub Gist (Private)** เป็น Cloud Storage ส่วนตัว 100% ฟรีตลอดชีพ ไม่ต้องมี Server และไม่ต้องผูกบัตรเครดิต พร้อมออกแบบ **"ปุ่มลับ & Easter Egg"** ในสไตล์ **World-Class Glassmorphism** เพื่อความสวยงาม หรูหรา และใช้งานง่าย

---

## ✨ ไฮไลท์ฟีเจอร์ใหม่ (Key Features)

### 1. 🕵️‍♂️ ทางเข้าลับ (Secret Access Points)
- **ปุ่มลับในเมนูตั้งค่า:** เพิ่มปุ่มแคปซูลแก้วเงาดีไซน์มินิมอล `☁️ คลาวด์ซิงค์ (GitHub Gist) [PRIVATE]` ใต้ปุ่มสำรองข้อมูลในหน้าตั้งค่า (⚙️)
- **Easter Egg แตะ 3 ครั้ง:** แตะที่ชื่อเดือน/หัวข้อปฏิทิน (`#monthLabel`) ติดกัน 3 ครั้ง เพื่อเปิดหน้าต่าง Cloud Sync ขึ้นมาทันที

### 2. 💎 หน้าต่าง Cloud Sync Modal (World-Class Glassmorphism)
- **สถานะการเชื่อมต่อแบบ Realtime:** มีสถานะไฟกระพริบ (🟢 เชื่อมต่อแล้ว / 🟠 พร้อมสำรอง / ⚪ ยังไม่เชื่อมต่อ) พร้อมแสดงเวลาซิงค์ล่าสุด และลิงก์เปิดดู Gist จริงบน GitHub
- **ช่องกรอก GitHub Personal Access Token (PAT):** 
  - ซ่อนรหัสแบบ Password พร้อมปุ่ม 👁️ เปิด/ปิดการมองเห็น
  - ปุ่มลัด `🔑 สร้าง Token บน GitHub` กดปุ๊บจะเปิดหน้าสร้าง Token ที่ตั้งชื่อและติ๊กสิทธิ์ `gist` ให้ทันที
- **ช่องกรอก Gist ID:** สามารถเว้นว่างได้ ระบบจะสร้าง Private Gist ให้อัตโนมัติในการกดสำรองข้อมูลครั้งแรก
- **⚡ Auto-Sync Toggle:** ตัวเลือกเปิด/ปิดการสำรองข้อมูลขึ้น Cloud อัตโนมัติทุกครั้งที่มีการแก้ไขและบันทึกข้อมูล
- **Action Buttons:**
  - 📤 **สำรองข้อมูลขึ้น Cloud (Backup)**: อัปโหลดข้อมูลทั้งหมดขึ้น Gist (ทั้ง ot_cal, เงินเดือน, วันลา, การตั้งค่า, วันหยุด)
  - 📥 **ดึงข้อมูลกลับ (Restore)**: ดาวน์โหลดข้อมูลจาก Gist กลับมาเขียนทับในเครื่อง พร้อมระบบตรวจสอบความถูกต้อง (Validation)
  - 🧪 **ทดสอบการเชื่อมต่อ**: ตรวจสอบความถูกต้องของ Token พร้อมดึงชื่อโปรไฟล์ GitHub (@username)
  - 🗑️ **ล้างการเชื่อมต่อ**: ล้าง Token ออกจากเครื่องอย่างปลอดภัย

## 🛠️ ไฟล์ที่ได้รับการพัฒนาและแก้ไข

| ไฟล์ | รายละเอียด |
|------|-----------|
| `js/cloud.js` | โมดูลหลักสำหรับจัดการการเชื่อมต่อ GitHub Gist API, การอ่าน/เขียนข้อมูล, และ Event Listeners |
| `js/data.js` | เชื่อมต่อระบบ Auto-Sync เข้ากับฟังก์ชัน `refreshHistory()` |
| `js/app.js` | เรียกใช้งาน `initCloudEvents()` ตอนเริ่มต้นแอปพลิเคชัน |
| `index.html` | เพิ่มปุ่มลับในเมนูตั้งค่า และเพิ่มโครงสร้าง Modal `#cloudSyncOverlay` พร้อม Cache Busting |
| `css/style.css` | เพิ่มสไตล์ Glassmorphism, Micro-animations, Pulsing Dot, และ Gradient Badges |
| `sw.js` | อัปเดต Cache Version เป็น `ot-v58` และเพิ่ม `./js/cloud.js` ในรายการแคช |

## 🔒 ความปลอดภัย (Security & Privacy)
- ข้อมูลบันทึกเป็น **Private Gist** เท่านั้น (บุคคลภายนอกไม่สามารถค้นหาหรือเข้าถึงได้)
- Token ถูกเก็บไว้ใน `localStorage` ของอุปกรณ์ผู้ใช้ ไม่มีการส่งผ่าน Server ตัวกลางใดๆ
- ขอสิทธิ์เฉพาะ scope `gist` ไม่สามารถเข้าถึง Repositories อื่นๆ ในบัญชี GitHub ได้
