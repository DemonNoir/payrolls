# Project Rules

## UI Redesign & Workflow Standard
ทุกครั้งที่มีการร้องขอให้รีดีไซน์ UI (User Interface) ให้ทำตามข้อกำหนดต่อไปนี้เสมอ:
1. **World-Class Design**: ให้ออกแบบในสไตล์พรีเมียมระดับโลก โดยต้องมีองค์ประกอบของ Glassmorphism, Micro-animations, และ Gradients ที่สวยงาม
2. **Walkthrough Documentation**: เมื่อทำการออกแบบและแก้ไขโค้ดเสร็จแล้ว ให้สร้างไฟล์ Walkthrough เพื่อสรุปการเปลี่ยนแปลง (แคปเจอร์หน้าจอ/วิดีโอ) และบันทึกไฟล์นี้ลงในโฟลเดอร์ `docs/`
3. **Version Control**: เมื่อทำงานทั้งหมดเสร็จสิ้น (แก้ไขโค้ดและสร้างเอกสารครบถ้วน) ให้ทำการ `git add`, `git commit` และ `git push` งานขึ้นไปยัง GitHub เสมอ

## PWA Cache Busting & Version Control
ทุกครั้งที่มีการแก้ไขไฟล์ โค้ด (HTML, CSS, JS) ในโปรเจกต์นี้ เอเจนต์ **ต้องทำการหักล้างแคช (Cache Busting)** เสมอก่อน Push โค้ด โดยปฏิบัติตามกฎ 2 ข้อนี้:
1. **อัปเดตไฟล์ `index.html`:** หากมีการแก้ไฟล์ .js หรือ .css ต้องหาตัวเลขเวอร์ชันปัจจุบัน (เช่น `data.js?v=44`) แล้วบวกเพิ่ม 1 เสมอ (ห้ามเดาตัวเลขเดิม ให้ใช้ Regex หรือค้นหาเวอร์ชันปัจจุบันก่อน)
2. **อัปเดตไฟล์ `sw.js`:** ต้องเปลี่ยนค่า `const CACHE` (เช่นจาก `ot-v38` เป็น `ot-v39`) ทุกครั้งที่มีการอัปเดตระบบ เพื่อให้ Service Worker โหลดไฟล์ใหม่จากเซิร์ฟเวอร์
หากไม่ทำตาม ผู้ใช้จะเจอปัญหาแอปค้างหรือโหลดโค้ดเก่าเสมอ
